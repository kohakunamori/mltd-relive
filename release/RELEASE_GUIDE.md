# mltd-relive 本地服务器与客户端下载

适用于已经停止运营的《偶像大师 百万人演唱会！剧场时光》繁体中文版和韩文版客户端。**首次使用只需下载一份电脑端服务器，再下载一份对应语言的安卓客户端**，按下方步骤连接。

这是非官方本地服务器。游玩时需要保持电脑端服务器运行；游戏资源仍由客户端从远端下载，不是下载一个程序就能完全离线游玩。

## 一、下载哪些文件

### 电脑端：按系统选择一份

| 电脑系统 | 下载 | 使用方式 |
| --- | --- | --- |
| Windows | [下载服务器]($download_url/${standalone_prefix}-windows.exe) | 放进固定的运行目录后打开；端口权限不足时以管理员身份运行。 |
| Ubuntu | [下载服务器]($download_url/${standalone_prefix}-ubuntu) | 按下方命令启动，需要图形显示环境。 |
| macOS | [下载服务器]($download_url/${standalone_prefix}-macos.zip) | 解压后打开其中的应用。 |

Ubuntu 用户请同时保留[第三方许可说明]($download_url/${standalone_prefix}-ubuntu-NOTICES.txt)。该文本文件不是启动程序。

### 安卓端：按游戏语言选择一份

| 游戏语言 | 下载 |
| --- | --- |
| 繁体中文 | [下载繁中修正版客户端]($download_url/mltd-relive-game-client-zh-fixed.apk) |

## 二、首次连接与登录

1. **连接网络。** 让电脑与安卓设备处于可互相访问的局域网中。电脑防火墙需要允许服务器在这个网络内通信。
2. **启动主服务器。** 打开电脑端程序，选择与客户端一致的语言，点击“启动服务器”（`Start Server`），等待状态显示 `Started`。首次使用会自动初始化数据库，不需要先点击重置按钮。
3. **启动内置 DNS。** 使用本指南的连接方式时，再点击“启动 DNS 服务器”（`Start DNS Server`），等待它也显示 `Started`。**主服务器和 DNS 是两个独立开关，不会一起自动启动。** 已有自建 DNS 解析方案的用户可继续使用自己的配置。
4. **设置手机 DNS。** 记录服务器窗口显示的电脑局域网 IPv4，将安卓设备当前 Wi-Fi 的 DNS 设为这个地址。不要填写 `127.0.0.1`。
5. **安装并登录客户端。** 安装上方对应语言的修正版安装包，打开游戏，在标题画面进入“密码继承 / 引继”。首次使用默认完整存档时，输入下方凭据；已有独立账户则使用自己的用户名和密码。

```text
用户名：MLTD0000
密码：relive2026
```

完整存档会在初始化时创建。需要多个独立账户时，可在服务器的“用户管理”（`User Management`）窗口创建；新账户从创建当时的完整存档复制数据，并非从教程开始的空白新号。详细说明见[账户使用指南]($repository_url/blob/main/README.md#完整存档用户与一般用户)。

以上是公开的默认凭据。请在受信任的局域网内使用，不要将服务直接开放到公网。

### Ubuntu 启动命令

在下载文件所在目录执行：

```bash
chmod +x ${standalone_prefix}-ubuntu
sudo ./${standalone_prefix}-ubuntu
```

程序需要图形显示环境；在 WSL 中使用时也需要图形显示支持。启动后仍需按上方步骤分别启动主服务器和内置 DNS。没有图形桌面的服务器不适合直接运行这个图形界面包。

## 三、已有存档如何升级

**升级前完全退出旧服务器，再备份整个原运行目录，尤其是 `mltd-relive.db` 和 `config.ini`。**

下载与电脑系统对应的新程序，继续使用原来的运行目录和数据库，再正常启动。不要删除存档，不要点击“重置数据”（`Reset Data`），也不要使用 `--reset`；这些是重新初始化数据的操作，不是升级步骤。

通常不需要清除手机上的客户端数据，也不需要重新安装相同的修正版客户端。需要保留某次下载版本时，请自行保存当时的程序文件；本页面的附件会在维护者手动发布时更新。

## 四、遇到问题先检查什么

| 现象 | 优先检查 |
| --- | --- |
| 游戏连接不上服务器 | 电脑与手机能否互相访问；主服务器与 DNS 是否都已启动；手机填写的 DNS 是否为正确的电脑局域网地址。 |
| 已设置 DNS，仍无法连接 | 排查手机的私人 DNS、VPN 或代理是否绕过了局域网 DNS；确认防火墙没有阻止局域网访问。 |
| 服务器启动失败 | 查看窗口日志中的端口占用或权限错误；本地 DNS / 加密接口通常需要使用 53 / 443 端口。 |
| 能连接，但资源下载失败 | 检查手机能否访问资源站，以及服务器中的远端资源地址配置；不要通过重置存档解决资源下载问题。 |
| 只有某个页面或游戏流程异常 | 查看[已知问题]($repository_url/blob/main/KNOWN_ISSUES.md)，反馈时附上客户端语言、操作步骤、错误截图和服务器日志。 |

部分活动、商店与在线社交功能尚未完整支持。更多配置见[完整使用说明]($repository_url/blob/main/README.md)，版本变化见[更新记录]($repository_url/blob/main/RELEASE_NOTES.md)。
